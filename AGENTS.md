# RepoGenesis Agent Notes

## Roadmap Tracking
- `docs/ROADMAP_STATUS.md` is the source of truth for the current roadmap position.
- At the start of each substantive progress update and final response, state the current roadmap position in the form:
  - `Roadmap Position: <phase> / <status>`
- When implementation meaningfully changes phase status, update:
  - `docs/ROADMAP_STATUS.md`
  - `docs/ACTIVE_CONTEXT.md`
  - `docs/ROADMAP.md` if completion markers changed

## Scope Discipline
- Prefer stabilizing the current phase before opening the next structural phase.
- Keep large changes split by concern:
  - app UX
  - generator/schema
  - docs/process
  - optional skill layer
