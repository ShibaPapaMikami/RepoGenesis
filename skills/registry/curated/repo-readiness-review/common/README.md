# Repo Readiness Review

## Purpose
Use this skill after RepoGenesis has produced a draft or repository ZIP.

The skill should help review:

- missing project intent or ownership
- unresolved assumptions that still block implementation
- security and compliance gaps
- weak repo structure or workflow defaults
- missing runbooks, versioning, and release guidance

## Notes
- This is a RepoGenesis-curated wrapper, not a vendored provider-owned skill package.
- Provider-specific artifacts follow each tool's official extension mechanism.
