# Frontend Design Direction

Create a memorable, production-grade frontend direction for the current repository.

Before coding:
- clarify the purpose, users, and constraints
- commit to one bold aesthetic direction
- decide what visual element should feel unmistakable

Implementation rules:
- avoid generic AI-looking layouts, fonts, and color choices
- use stronger typography, background atmosphere, and spatial contrast
- keep motion intentional and support the chosen aesthetic
- ship real working code, not mock styling

Output:
1. visual direction
2. implementation plan
3. working code changes
4. final polish notes
