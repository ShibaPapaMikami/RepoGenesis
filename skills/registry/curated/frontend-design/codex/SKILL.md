# Frontend Design Direction

Create a distinctive, production-grade frontend direction for the current repository.

Before coding:
- identify the page purpose, audience, and technical constraints
- choose one strong aesthetic direction and name it
- decide the one visual trait the user should remember

When implementing:
- avoid generic AI aesthetics and default-looking component layouts
- use purposeful typography, atmospheric backgrounds, and confident spacing
- make motion intentional instead of scattering small effects everywhere
- keep the code working, accessible, and production-usable

Return:
1. aesthetic direction
2. layout and interaction plan
3. working implementation
4. polish checks
