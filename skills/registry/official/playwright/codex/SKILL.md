# Playwright Browser QA

Use this skill when a browser flow, page state, or UI regression needs verification.

Workflow:
1. Reproduce the user flow in the browser.
2. Capture failures with the smallest useful scope.
3. Confirm whether the issue is visual, behavioral, or data-related.
4. Turn the observation into a concrete fix or regression test.
5. Summarize what was verified and what still needs manual review.
